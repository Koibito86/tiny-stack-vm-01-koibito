# tiny-stack-vm-01 Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a byte-exact, minimal-size tiny stack VM entry for `tiny-stack-vm-01-run-20261122` that scores 1,000,000 and clears the transcript gate before `2026-11-25T04:00:00Z`.

**Architecture:** One dependency-free `main.ts` implements the ISA as a compact numeric opcode switch and writes answer files for every instance; the kit's `vm.mjs` stays outside the repo as the differential oracle. Same byte for byte as the starter `LICENSE`, nothing else ships.

**Tech Stack:** Node 22.23.5, TypeScript type-stripping (erasable syntax only), kit CLI `cli/makefun.mjs`, Hermes transcript bundle, GitHub repo under `Koibito86`.

**Spec:** `docs/superpowers/specs/2026-11-24-tiny-vm-design.md` in this repo, plus the kit's `RULES.txt` and `program/generator/subject/ISA.md`.

## Global Constraints

- Runtime: `node /bot/main.ts`, Node 22, no install step, no network, 1 CPU, 512 MB, 60 s wall for all 40 instances.
- Inputs `/input/<id>/{program.bin,input.bin}`; outputs `/output/<id>/{stdout.bin,exit.txt}`.
- Program ≤ 65,535 B; stack ≤ 256; call stack ≤ 64; memory 256 words; steps ≤ 1,000,000; output ≤ 65,536 B.
- Trap codes 2–11 exactly as ISA.md; output before a trap is retained.
- Repo ≤ 8,192 B total; tie-break `size_bytes`, with byte-identical starter files counting 0.
- Session `created_at` must be ≥ `opens_at 2026-11-22T04:00:00Z` — active session is `2026-11-24T19:09:20` local (19:09Z), eligible.
- Deadline `2026-11-25T04:00:00Z`; `entry_fee: null`; no late entry path.
- Transcripts: ≥80% of counted entry lines authored in session; Hermes needs ≥30% first-authored lines, ≥5 assistant text/thinking turns, ≥2 writes to the entrypoint.

## Review Focus

- `MUL` above 2^53, `-2147483648 / -1`, `% -1`, negative DIVU/MODU/LTU → test vectors compare against `vm.mjs` in Task 2.
- Shift counts 32, 33 and negative, SHR vs SHRU → same differential vectors.
- Stack overflow/underflow, call depth 64, RET empty, memory address bounds, step limit, output limit → same differential vectors.
- Trap output retention and exit-code bytes → practice `grade-local` in Task 3 checks all 40 instances.
- Transcript authorship / bundle discovery from a parent-directory session → `bundle --dry-run` in Task 5.
